# Instructions for AI assistants

This is the user's learning project: they design the CPU and OS themselves.
Explain, review, and argue with their design; write scaffolding (build scripts, testbenches, tooling) when asked; don't write core RTL or kernel code for them unless they ask for it explicitly.

At the start of a session, read `README.md`, then `docs/ROADMAP.md` ("Current position" and the session log), then `docs/DECISIONS.md`.
At the end of a session that changed anything, update "Current position" and add one session-log line in `docs/ROADMAP.md`.
Change a decision only by editing its entry in `docs/DECISIONS.md` and adding a dated line under "Changes".
